# 09. Capstone Projects and Portfolio

## Goals

- Combine everything you learned
- Build real-world apps
- Prepare for interviews and job applications

## Recommended projects

- Personal portfolio website
- Full-stack task manager
- Blog platform
- E-commerce app
- AI-assisted productivity tool

## Portfolio checklist

- [ ] Clear project description
- [ ] GitHub repository
- [ ] Demo link
- [ ] README with setup instructions
- [ ] Screenshots or UI preview
- [ ] Tested code
