# Learning Roadmap

This repository is organized as a full learning roadmap for becoming a modern software developer.

## Roadmap overview

1. Foundations
2. Programming basics
3. Python development
4. Web fundamentals
5. Databases
6. Backend development
7. Frontend development
8. DevOps and deployment
9. Capstone projects and portfolio

## Suggested order

- Start with Git, terminal usage, and problem solving.
- Learn programming concepts before frameworks.
- Build small projects often.
- Keep notes in `notes/`.
- Practice in `exercises/`.
- Build portfolio-ready work in `projects/`.

## Weekly rhythm

- 4 days: learning + coding
- 1 day: projects / notes
- 1 day: review / recap / documentation

## Success checklist

- [ ] Can use Git confidently
- [ ] Can read and write basic Python
- [ ] Understand HTML, CSS, JS
- [ ] Can build APIs
- [ ] Can work with databases
- [ ] Can deploy apps
- [ ] Has 2-3 portfolio projects
